# 显示对象（CDspObj）基类属性与相关子 opcode（任务 D 补充，Claude 研究）

依据：`out/ac2_ML.c` 反编译；CDspObj 虚表 VA 0x005136c0（用 `scripts/read_vtable.py <VA>` 从 exe 读取虚表项）。全部为【静态推断】，尚未动态验证；字段偏移相对对象指针。

## 通用属性设置：`90:38` = SetProperty(objId, propId, a, b)

虚函数 +0x5c = FUN_00421530(propId, a, b)，基类 switch：

| propId | 效果 |
|---|---|
| 0 | 位置 (a,b)，即 +0x2c |
| 1 | 混合模式 a |
| 2 | alpha a |
| 0xC0 / 0xC1 / 0xC4 / 0xC5 | 写 +0x08 / +0x10 / +0x4c / +0x50 |
| 0x8000 | +0x88=a, +0x8c=b |
| 0x8001 | +0x90=a |
| 0x8100 | +0x24=a |
| 0x8101 | +0x28=a（a<2，否则返回错误） |
| 0xFFFF | 标志位：a 为掩码（0 视为全 1），b 非 0 置位、0 清位 |
| 0x7FFF0000 | +0xC4=a |
| 0x7FFFFFFF | 16 槽数组：槽[a]=b（a<0x10） |
| 其他 | 返回 -0xffff；FUN_0044b820 将其转为脚本错误码 5（-0xffff）或 0xFE（其他非零） |

子类（CDspObjSprite 等）可覆写 +0x5c 扩展属性，未逐类核对【未知】。

## 其他 90 组对象操作

- `90:30` objId, v → 虚函数 +4（+0x14 字段，递归子对象）。
- `90:32` objId, v → 虚函数 +0x48（alpha）。
- `90:33` objId, x, y → 虚函数 +0x2c（位置，同时移动子对象）。
- `90:34` objId, v → FUN_004212a0（+0xb8）。
- `90:38` objId, propId, a, b → 通用属性，见上。弹栈顺序：先 b、a、propId，最后 objId（与 90:56 同方向）。
- `90:54` objId, v → 虚函数 +4（与 90:30 相同虚槽，但经渲染管理器 DAT_005485ec 外的另一对象表 FUN_00446780，即精灵对象表）。

## `90:56` 精灵一次性配置

脚本压栈顺序（先压）：`objId, x, y, imageSlot, blendMode, alpha, priority`；VM 依次弹出 priority…objId。

FUN_0042ca00：`FUN_0042ceb0(imageSlot)`（按图像槽取得纹理，槽无效返回 0x80000001→脚本错误），然后 +0x2c(x,y)、混合模式 +0xb0、虚函数 +0x48(alpha)、虚函数 +0x54(priority)。参数范围由 FUN_004a8800（imageSlot 0..0x3fff）、FUN_004a88f0（blend）、FUN_004a8a70（alpha ≤0x100）、FUN_004a8860（priority ≤0xffff）校验，超界直接抛脚本错误。已与 FUN_0048b600 的弹栈次序核对。
`90:57`（弹 imageSlot、objId）是只换图的版本（FUN_0042cda0 方向，未逐行核对）。

## 对 OpenBGI 的含义

- 渲染层所需对象模型是“基类 CDspObj + 位置/alpha/混合模式/优先级/子对象链表”，以通用属性 ID 扩展；alpha 取值范围 0..0x100（不是 255）。
- 图像槽（0..0x3fff）是脚本侧的位图句柄，由 90:11/12/13/18/1F 等管理，精灵只引用槽号。
- 属性设置、位置更新都带递归子对象，实现时需保留“父位置 + 子偏移”语义。
