# 输入子系统与 80:12–80:1C（任务 D，Claude 研究）

依据 `out/ac2_ML.c`：包装 FUN_00496c70–FUN_00496e80（160407 行起）→ 输入层 FUN_0047b530–FUN_0047c750。工具：`scripts/read_dwords.py`（读 exe 内的初始映射表）。全部【静态推断】，默认映射表为【从 exe 初始数据直接读取，已验证】。

## 结构

- **轮询式**：每次查询用 `GetAsyncKeyState(虚拟键码)`（FUN_0047b530），不是 DirectInput 事件；鼠标按键用同一接口（VK 1/2/4/5/6）。系统交换鼠标左右键时（FUN_0049de20）自动调换 1↔2。“输入编号 7” 是特殊项（FUN_004789b0，疑为手柄/滚轮伪键）。`0x0E`、`0x0F` 等不存在的 VK 号用于滚轮伪键（默认映射到逻辑位 0x40/0x80，疑为滚轮上/下）。
- 每个物理输入编号有 0x18 字节的状态记录（`0x00548700 + n*0x18`）：按下标志、边沿标志、事件累计等；FUN_0047bc40(n) 返回“自上次读取以来的按下次数 | 0x80000000 若为新按下”，读后清零累计（因此是**读取即消耗**的边沿检测）。编号 0xC1–0xC4 是虚拟组合输入（对应 4 张列表的“任一按下”）。
- **逻辑输入掩码**（32 位，FUN_0047c190 中硬编码的 24 个位 + 每位一张以 0 结尾的物理编号列表）。默认映射（初始数据）：

| 逻辑位 | 默认物理输入（VK） |
|---|---|
| 0x00000001 | 鼠标左键(1) |
| 0x00000002 | 鼠标右键(2) |
| 0x00000004 | 鼠标中键(4) |
| 0x00000010 / 0x20 | 鼠标 X1(5) / X2(6) |
| 0x00000040 / 0x80 | 伪键 0x0E / 0x0F（滚轮上下推断） |
| 0x00000100 | 回车(0x0D) |
| 0x00000200 | 空格(0x20) |
| 0x00001000 / 0x2000 / 0x4000 / 0x8000 | 方向键 上(0x26) / 下(0x28) / 左(0x25) / 右(0x27) |
| 0x00010000 … 0x01000000 | 数字 1…9：主键盘 0x31..0x39 与小键盘 0x61..0x69 |
| 0x02000000 | 数字 0：0x30 与 0x60 |
| 0x40000000 | Tab(0x09) |
| 位 31(0x80000000) | “跳过键”：Ctrl(0x11) 等列表（0x0052f320 起），按下时置位；由 FUN_0047bf50 汇总 |

  映射可被脚本改写（80:1B），所以上表只是初始值。
- **鼠标区域（按优先级）**：80:18 把一个矩形和回调对象按“优先级”插入有序链表（FUN_0047b650，节点 0x1c 字节：优先级、矩形 4 个值、对象指针），80:19 按优先级移除（FUN_0047b720）。`FUN_0047b7f0` 判断当前鼠标位置是否落在“最高优先级区域”内，决定鼠标点击是否送给低层（弹窗/按钮遮挡低层输入的机制）。`FUN_0047b7d0` 检查传入的优先级是否不低于当前最高区域优先级，才允许读取输入。

## 子 opcode

| 子 opcode | 含义（推断） |
|---|---|
| `80:12` | (地址) 地址指向以 0 结尾的物理输入编号数组，累加各项 FUN_0047bd70（状态）并压入 |
| `80:13` | 压入全局输入状态 `DAT_005486f0`（疑为当前输入模式/焦点标志） |
| `80:14` | (值) 写 `DAT_0052f5bc`（是否启用“跳过键”聚合，FUN_0047bf50 末尾使用） |
| `80:15` | (值) 写 `DAT_00549f04`（输入模式相关标志） |
| `80:17` | 压入 FUN_0047bf50：是否有“跳过键”被按下/按住（遍历跳过列表，需 DAT_0052f5bc≠0） |
| `80:18` | (优先级) 注册鼠标区域；参数左移 16 位并与 0xFFFF 合并后传入 FUN_0047b6a0、FUN_0047b6f0（两张区域链表：`DAT_005486b4` 与 `DAT_005486d0`），随后 FUN_0047c020 刷新 |
| `80:19` | (优先级) 移除鼠标区域，同样合并参数，FUN_0047b760/b770 从两张链表移除 |
| `80:1A` | (优先级) 读取逻辑输入掩码：FUN_0047c020(优先级<<16 \| 0xFFFF)：先看优先级是否允许，再取键盘/鼠标按键聚合，最高位=跳过键；鼠标 VK 1/2/4/5/6 分别映射到位 0x1/0x2/0x4/0x10/0x20 |
| `80:1B` | (掩码, 地址) 把地址处最多 15 个非零编号写入对应逻辑位的映射列表（重映射按键） |
| `80:1C` | (掩码) 遍历掩码中置位的逻辑位对应的物理编号，调用状态读取并累加，压入结果（FUN_0047c190；与 80:12 区别是以逻辑位而非地址指定） |

## 对 OpenBGI 的含义

- 逻辑层很简单：32 位掩码 + 默认键位表 + 可重映射。SDL3 的键盘/鼠标/手柄事件可映射为同样的“VK 编号”后沿用原逻辑；游戏用的是**查询当前状态**，不是事件回调，所以用 SDL 的 `SDL_GetKeyboardState`/`SDL_GetMouseState` 轮询即可。
- “读取即消耗边沿”要自己实现：每个物理输入记录按下次数和新按下标志。
- 鼠标区域优先级机制是 UI 遮挡的关键，需要保留。
